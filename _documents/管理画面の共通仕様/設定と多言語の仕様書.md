# 管理画面の設定と多言語の仕様書

[管理画面の共通仕様書](../管理画面の共通仕様書.md)の 8・9 章。**基準は Questionnaire（Q）の実装**。
**アプリの接頭辞は `<APP>_` と書く**（Q は `QUESTIONNAIRE_`、AtomFeed・CalendarFeed・IdP の値は 8.4）。

## 8. 設定

### 8.1 読み込みの順

- 優先は **`{名前}.local.json` ＞ 環境変数 ＞ `{名前}.json`**（`App_Data/Parameters/`）。ファイルのキーは環境変数名へ写す
  （`Q.Web/Program.cs:40-44`、`Q.Web/Services/ParameterFileAliases.cs:22-116`）
- **`<APP>_*_FILE`** で、ファイルの中身を設定値として読む（Docker secrets・Kubernetes Secret）。64 KB まで。
  値は例外やログへ出さない（`Q.Web/Services/SecretFileConfigurationProvider.cs:1-24`）
- 画面から変えられる設定（アプリケーション設定）は `Core_AppSettings` に置き、**外部設定に値があれば外部設定が勝つ**
  （画面には「固定」と出す）（`Core.Data/Stores/AppSettingStore.cs:10-31`、`Q.Web/Program.cs:436-438`、
  `Q.Web/Endpoints/AdminSettingsEndpoints.cs:36-40`）
- 書き間違い（知らない値・範囲外・壊れた URL や正規表現）は**起動時に止める**。黙って既定へ落とさない
  （`Q.Web/Program.cs:412-425, 432-434, 452-459`）

### 8.3 SAML と Pleasanter のログインの設定

いずれも `App_Data/Parameters/Authentication.json` と画面（`settings.saml`・`settings.pleasanterSso`）から変えられる。
外部設定に値があれば外部設定が勝つ（`Q:App_Data/Parameters/Authentication.json`、`Q.Web/Program.cs:436-460`）。

| 設定（`<APP>_SAML_*`） | 既定 | 根拠 |
|---|---|---|
| `ENABLED`・`ENTITYID`・`IDPENTITYID`・`SINGLESIGNONURL`・`IDPCERTIFICATE`（有効なら 4 つとも必須） | 無効 | `Q.Web/Services/SamlOptions.cs:50-54, 139-163` |

### 8.4 アプリ間の差

| 観点 | Q | AtomFeed | CalendarFeed | IdP |
|---|---|---|---|---|
| 接頭辞 | `QUESTIONNAIRE_` | `ATOMFEED_` | `CALENDARFEED_` | `IDP_` |
| SAML・Pleasanter のログインの名前 | 8.3 のとおり | 同じ名前（画面から変えられる） | 同じ名前。ファイルは Pleasanter に倣った階層 | 無い |
| `<APP>_ADMIN_TWOFACTOR` | 外部設定だけ | 画面からも変えられる | 同じ | `IDP_TOTP_MODE`（別物） |
| パスワードの最低の長さ | `PasswordMinimumLength`（起動時） | `ATOMFEED_PASSWORD_MINIMUMLENGTH`（画面から、8〜128） | 同じ | 無い |
| 監査ログの保持 | 1〜36500 | 0〜36500（0 は消さない） | 同じ | 0〜36500 |
| セッション・締め出し・招待の長さ | 定数 | 定数 | **設定できる**（`SESSION_RETENTIONPERIOD`・`LOCKOUT_COUNT`・`LOCKOUT_PERIOD`・`PENDING_AUTHENTICATION_PERIOD`・`INVITATION_PERIOD`） | 設定できる（`SESSION_LIFETIME_MINUTES`・`LOGIN_MAX_FAILURES` など） |
| 秘密の鍵 | 必須・自動生成しない | 自動生成する（`…_SECRET_KEY_AUTOGENERATE=false` で止める） | 自動生成しない（`--generate-secret-key --write`） | 自動生成する |
| `*_FILE` | `<APP>_*_FILE` | `<APP>_*_FILE` なら何でも | 既知の名前だけ | `IDP_*_FILE` |
| 管理画面の入口 | `<APP>_ADMIN_PATH` | `/admin` 固定 | 同じ | `IDP_ADMIN_PATH` |
| 公開 URL | `<APP>_MAIL_BASEURL`（メール用） | `ATOMFEED_PUBLIC_BASEURL`（cookie の `Secure`・同一オリジン・ACS・招待 URL） | 同じ | `IDP_ISSUER` |

根拠は [各アプリの差異の一覧](各アプリの差異の一覧.md)の A.4・A.6。AtomFeed は `AF.Web/Services/AppSettingDefinitions.cs:151-260`・
`AF.Web/Services/AdminAuthOptions.cs:26-44`、CalendarFeed は `CF.Web/Services/FixedParameters.cs:40-46, 135-166`、
IdP は `IdP.Web/IdpOptions.cs:28-220`。

## 9. 多言語

### 9.1 対応言語と決め方

- Q は 7 言語（`ja`・`en`・`zh`・`de`・`ko`・`es`・`vi`）。データの既定は `ja`（`Q.Core/Localization/SupportedLanguages.cs:23-26`、
  `Q.Core/Definitions/LocalizedText.cs:14`）
- **サーバの応答の言語は `Accept-Language` だけで決める**。画面は自分が描いている言語をこのヘッダで送る
  （`Q.Web/Localization/RequestLanguage.cs:5-30`）
- 管理者ごとの言語（`Core_AdminUsers.Language`）は画面の初期値。空なら未選択（ブラウザに従う）
  （`Q.Web/Endpoints/AdminUserEndpoints.cs:294-321`、`Core.Data/Stores/AdminUserStore.cs:170-172`）
- 画面の文言の落とし先は 選択した言語 → `en` → `ja`（Q `_documents/多言語対応方針.md:31-36`）

### 9.2 サーバのメッセージキー（共通の候補）

文言は載せない。鍵は `Q.Web/Localization/ServerMessageKeys.cs`、文言は `Q.Web/Localization/ServerMessages.cs`（1230 行、7 言語）。

| 鍵 | 意味 | 使う所 |
|---|---|---|
| `auth.invalidCredentials` | 資格情報が違う（**段階を区別しない**） | `/login`・2 要素 |
| `auth.loginIdAndPasswordRequired` | ログイン ID とパスワードが要る | `/setup` |
| `auth.administratorAlreadyExists` | 最初の管理者は既に居る | `/setup` |
| `auth.loginTemporarilyLocked` | 締め出し中 | `/login`・2 要素 |
| `auth.enrollmentRestartRequired` | 登録をやり直す | `/enroll/complete`・`/me/totp/complete` |
| `auth.totpAlreadyEnrolled` | 登録済みなので途中状態から登録できない（Q#695） | `/enroll/*` |
| `auth.totpCodeMismatch` | 数字が合わない（登録時） | `/enroll/complete`・`/me/totp/complete` |
| `auth.twoFactorDisabled` / `auth.twoFactorRequired` / `auth.twoFactorNotEnrolled` | 2 要素が無効・必須・未登録 | 登録・解除 |
| `auth.passwordTooShort`（`{0}`=最低の長さ）/ `auth.passwordSameAsLoginId` / `auth.passwordPolicyMismatch` | パスワードの条件 | `/setup`・招待・`/me/password` |
| `users.roleNotSupported` / `users.notFound` / `users.duplicateLoginId` / `users.invalidInput` | 管理者の操作の入力 | `/users/**` |
| `users.selfNotAllowed` / `users.lastAdministrator` | 締め出しの防止 | `/users/**`・端末 |
| `users.operationTemporarilyLocked` / `users.currentPasswordRejected` | パスワードの再確認 | `/me/**` |
| `users.invitationInvalid` | 招待が使えない（**理由を区別しない**） | `/invitations/accept` |
| `users.unsupportedLanguage` | 対応外の言語 | `/me/language` |

| `invitation.mail.subject` / `invitation.mail.body`（`{0}`=URL、`{1}`=期限） | 招待メール | 管理者の追加 |
| `settings.valuesRequired`・`settings.keyNotManaged`・`settings.fixedExternally`・`settings.valueTooLong`・`settings.notBoolean`・`settings.notInteger`・`settings.belowMinimum`・`settings.aboveMaximum` | 設定画面の検証（汎用） | `/settings` |

根拠: `Q.Web/Localization/ServerMessageKeys.cs:21-79, 114-118, 217-265`。

アプリ固有の鍵（共通にしない）: `surveys.*`・`templates.*`・`outbox.*`・`autoReply.*`・`responseNotification.*`・
`maintenance.*`、`settings.*` のうちメール・Pleasanter・添付・配色など項目に結び付くもの（同 `:83-331`）。

`{ code }` で返し、文言を画面が作るもの（サーバの鍵を持たない）: SAML の `samlError`（`invalid`・`unknown-user`・`disabled`）、
Pleasanter のログインの `code`（`setup-required`・`not-allowed`・`disabled`・`unknown-user`・上流エラー）、
SAML の設定試験の `code`（`invalid-url`・`not-metadata`・`fetch-failed`）。
