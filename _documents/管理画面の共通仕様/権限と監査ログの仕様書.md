# 管理画面の権限と監査ログの仕様書

[管理画面の共通仕様書](../管理画面の共通仕様書.md)の 6・7 章。**基準は Questionnaire（Q）の実装**。

## 6. 役割と権限

### 6.1 考え方

- **操作は役割ではなく権限で要求する**。権限の名前は `対象.操作`。役割を足しても、権限の表に 1 行足すだけで済む
  （`Q.Web/Services/AdminPermissions.cs:7-17`）
- 知らない役割は**何もできない**（通すより安全な壊れ方）（同 `:111-115, 161-169`）
- 認可は要求のたびに、DB から読んだ役割で表を引く（cookie へ焼かない）（`Q.Web/Program.cs:539-550`）
- 役割の受け取りは**定義済みの名前だけ**。数値や未知の名前は 400（`Q.Web/Endpoints/AdminUserEndpoints.cs:643-652`）
- 画面は `/session` の `permissions` で出し分ける（`Q.Web/Endpoints/AdminAuthEndpoints.cs:123-125`）

### 6.3 締め出しを防ぐ規則

| 規則 | 応答 | 根拠 |
|---|---|---|
| **最後の有効な Administrator は、無効化も降格もできない**。「有効」は無効でなく、**一度でもログインした**人（招待しただけの人は数えない） | 409 `users.lastAdministrator` | `Core.Data/Stores/AdminUserStore.cs:8-10, 107-115`、`Q.Web/Services/AdminUserService.cs:336, 378` |

## 7. 監査ログ

### 7.1 書き方

- 保管先は Core の `Core_AuditLogs`（`IAuditLogStore`）（`Core.Data/Stores/AuditLogStore.cs:69-83, 106-107`）
- **入口の集まりに 1 回掛ける**（`AuditLogFilter`）。1 つずつ書き足さない（`Q.Web/Services/AuditLogFilter.cs:8-28`）
- **読み取り（GET・HEAD）は残さない**。例外は明示したもの（救済トークンの照合）（同 `:70-75`、`Q.Web/Program.cs:1047`）
- **失敗も残す**。状態 400 以上を失敗とする。302 で返す SAML の失敗は 401・403 として残す
  （`Q.Web/Services/AuditLogFilter.cs:178-181`、`Q.Web/Endpoints/AdminSamlEndpoints.cs:684-702`）
- **要求本文と問い合わせ文字列は入れない**。入口が明示して預けた値（`AuditNotes`）だけを足す
  （`Q.Web/Services/AuditLogFilter.cs:221-242`、`Q.Web/Services/AuditNotes.cs:3-15`）
- 何も起きなかった問い合わせ（Pleasanter のログイン待ち）は残さない（`AuditNotes.Skip`）（`Q.Web/Services/AuditNotes.cs:56-67`）
- 1 回の操作で複数の端末を失効させたら、**1 端末 1 行**（同 `:108-130`）
- 書けなくても操作は通し、エラーをログへ出す（`Q.Web/Services/AuditLogFilter.cs:85-98`）
- 保持は `<APP>_AUDITLOG_RETENTION_DAYS`（既定 365、1〜36500）（`Q.Worker/AuditLogRetention.cs:21`、
  `Q.Web/Services/AppSettingsProvider.cs:363-367`）

### 7.2 項目

| 項目（`AuditEntry`） | Q が入れる値 | 根拠 |
|---|---|---|
| `OccurredAt` | サーバのローカル時刻の数字（旧の目盛りを保つ） | `Q.Web/Services/AuditLogFilter.cs:176-177` |
| `Action` | `"{METHOD} {経路の型}"`（型の制約を落とす。例 `POST /api/admin/users/{adminUserId}/role`） | 同 `:117-139` |
| `Succeeded` / `StatusCode` | 状態 < 400 / 状態 | 同 `:179-181` |
| `ActorKey` / `ActorLoginId` | 管理者 ID（GUID）/ ログイン ID。認証の外の試みでは null | 同 `:166-170, 193-197` |
| `TargetType` / `TargetId` | 明示した対象。無ければ経路の値（`adminSessionId`→`AdminSession`、`adminUserId`→`AdminUser`、ほかはアプリ固有） | 同 `:50-59, 199-219` |
| `DetailJson` | 経路の値と、預けた補足（日本語はそのまま。HTML に効く文字は逃がす） | 同 `:36-48, 221-242` |
| `IpAddress` | IPv4 を IPv6 の形で残さない | 同 `:141-155` |
| 入れないもの | パスワード・API キー・トークン・復旧コード・TOTP の数字・業務の本文 | `Core.Data/Stores/AuditLogStore.cs:6-9` |
